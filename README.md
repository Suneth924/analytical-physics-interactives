# Analytical Physics Lecture 1 — GitHub Pages

This is a self-contained student-facing web lecture. Images and both interactive simulations are embedded in `index.html`; no local asset folders are required. MathJax is loaded from jsDelivr, so students need Internet access for equations.

## GitHub Pages
Upload `index.html` to the root of your repository. Then enable Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
